# Фотографии техники

Сюда кладите реальные фото машин, грузовиков и спецтехники.

## Структура

Путь к папке с фото совпадает с ID техники в каталоге:

```
public/images/vehicles/<id>/1.jpg   ← главное фото карточки
public/images/vehicles/<id>/2.jpg
public/images/vehicles/<id>/3.jpg   ← и так далее (до 12 фото)
```

Пример: техника с `id = 1` (Toyota Camry) → `public/images/vehicles/1/1.jpg`.

Эти же пути прописаны в seed-данных (см. `backend/.../config/DataInitializer.java`),
поэтому после добавления файлов и перезапуска фото подтянутся автоматически.

## Важно

- **Порядок:** первый элемент списка `images` — главное фото в карточке.
- **Если файла нет** (или он битый) — вместо сломанной картинки показывается
  аккуратная заглушка с силуэтом и иконкой категории.
- **Пропорции:** карточки и галерея — 16:9, `object-fit: cover`.
- Форматы: `jpg`, `jpeg`, `png`, `webp`, `gif`, `avif`.

## Альтернатива: загрузка через админку

Фото можно загружать прямо из панели администратора (раздел «Автомобили» →
редактирование → «Фотографии»). Такие файлы сохраняются в каталог
`backend/uploads/vehicles/<id>/` и отдаются по тому же префиксу
`/images/vehicles/<id>/<файл>` — то есть оба способа совместимы.

После сборки фронта (`npm run build`) содержимое этой папки копится в
`backend/src/main/resources/static/` и раздаётся бэкендом.
